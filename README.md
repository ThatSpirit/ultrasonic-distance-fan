# Ultrasonic Distance Fan
Arduino project comprised of a HC-SR04 ultrasonic distance sensor feeding data into a 3-6v motor. Once an object enters the sensors set distance the DC motor gains power and will spin the connected fan.
## Important
'HC-SRO4.zip' is the library zip file for the library required for the ultrasonic sensor to work with the code committed.
